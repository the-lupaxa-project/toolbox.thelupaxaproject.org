# Lupaxa Web Toolbox

Browser tools for encoding, cryptography, DNS, data, development, and GitHub.
The tools run in the browser. The site is published at
<https://toolbox.thelupaxaproject.org/>.

## Prerequisites

- Python 3.13+
- Node.js 22+

## Local Development

```bash
make init
make install-dev
make mkdocs-serve
```
